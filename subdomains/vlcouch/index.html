Installation

Download, install, and start browsing in minutes.

  1. Download the installer

    Get VLCouchSetup from GitHub Releases.

  2. Run the installer

    The setup wizard installs VLCouch and adds a Start menu shortcut. Install VLC and FFmpeg manually or with one click in Settings.

  3. Add your library

    Launch VLCouch, set your movie and TV folders, then scan your library.

  4. Browse and play

    Browse your library, search for titles, and launch them in VLC with support for continue watching, show playlists, and more.

Frequently Asked Questions

Common questions about the offline movie library browser.

What is VLCouch?

VLCouch is an offline-first local media browser for Windows. It scans folders on your PC, catalogs movies and TV shows with poster thumbnails, and launches playback in VLC when you hit Play.

Do I need an account or internet connection?

No. VLCouch works entirely offline by default. Your files stay on your drives, thumbnails are generated locally with FFmpeg, and no cloud library or account is required. There is an optional feature for fetching plot summaries from Wikipedia, but this is disabled by default.

What do I need installed to run VLCouch?

Download and run VLCouchSetup from GitHub Releases — the installer bundles Python and the app. You also need VLC for playback and FFmpeg for thumbnails. If either is missing, open Settings in VLCouch to install them with one click via winget or use the download link shown there.

Is VLCouch affiliated with VideoLAN or VLC?

No. VLCouch is independent open source software and is not affiliated with VideoLAN or the VLC project.

Is VLCouch a media server?

No. VLCouch is a local media library browser and VLC launcher. It does not play media, transcode, or stream over the network. You browse files in VLCouch and play them in VLC.

Is VLCouch free?

Yes. VLCouch is free and open source under the GPL-3.0 license.
